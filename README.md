# Grant Ponting — Portfolio

Personal portfolio for Grant Ponting, a software developer and quality engineer.

## Stack

- [Astro](https://astro.build/)
- TypeScript
- Plain CSS

## Local development

```sh
npm install
npm run dev
```

The development server runs at `http://localhost:4321` by default.

## Verification

```sh
npm test
npm run build
```

## Production build

```sh
npm run build
npm run preview
```

Astro writes the static site to `dist/`.
